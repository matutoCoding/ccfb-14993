# 挡风玻璃光学畸变仿真检测系统

浏览器端的前挡风玻璃光学畸变仿真与检测系统:TypeScript + WebGPU,数据存 IndexedDB。

## 运行

```bash
pnpm install
pnpm dev        # 开发
pnpm build      # 类型检查 + 构建
pnpm test       # 精度校验测试
```

## 页面

| 页面 | 功能 |
| --- | --- |
| 车型档案 | 装车倾角、驾驶员眼点、A/B/HUD 区域划分,区域边界在玻璃轮廓上直接绘制 |
| 玻璃曲面 | 2-3 条控制曲线放样生成曲面,或粘贴点云(x y z)最小二乘拟合三阶多项式;内外玻璃 + PVB 夹层厚度;局部厚度不均 / 成型波纹 / 边部应力凸起三类缺陷,幅度位置可调 |
| 检测工位 | 按真实布置渲染斑马板(WebGPU,不支持时回退 CPU),条纹角度 / 周期 / 板距可调;路面视角模式模拟主驾动态,眼点移动可见车道线跳动 |
| 畸变分析 | 逐点屈光度热力图,A/B 区分别套限值并标红超限点;相机条纹图反推屈光度,与直接计算剖面对照 |
| 批次记录 | 按缺陷类型生成检测批次,记录每块玻璃的缺陷参数与判定结果,统计超标率,可导出 CSV |
| 设置 | 折射率、限值、计算分辨率;数据 JSON 导入导出 / 恢复出厂 |

内置三个测试车型:C200 轿车、X5 SUV、H9 旗舰轿车(带 HUD 区域)。

## 光学模型

- 夹层结构:空气 | 内层玻璃 | PVB | 外层玻璃 | 空气,四个球面/自由曲面界面逐面斯涅尔折射
- 曲面表示:高度场 z(x,y),双三次 Catmull-Rom 采样(C1 连续,梯度可用于光学计算)
- 屈光度:偏向角矢量对玻璃坐标的梯度(单位 dpt),符号约定与透镜光焦度一致
- 条纹反推:斑马板跳变沿亚像素定位(盒式像元模型精确反解)+ 无玻璃参考模型按序配对条纹相位,由板面位移反算偏向角再求梯度

## 精度(自动化测试保证)

- 已知曲率球面夹层玻璃,光线追迹屈光度 vs ABCD 矩阵解析解:误差 < 0.01 dpt(实测约 0.0009)
- 条纹反推 vs 直接计算:RMS 偏差 < 0.01 dpt(实测约 0.0016)
